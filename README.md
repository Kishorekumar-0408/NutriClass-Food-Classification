# NutriClass: Food Classification Using Nutritional Data

This project builds a multi-class classification system to predict exact food names based on nutritional attributes.

## Features
- Data preprocessing & feature engineering
- Multiple ML models comparison
- Strict diet-based food classification
- Business-ready prediction system

## Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn

## How to Run
1. Place dataset in `data/raw/`
2. Install dependencies:
   pip install -r requirements.txt
3. Run:
   python -m src.main
